Read this first

AI-900 is gone. AI-901 is the exam. Microsoft retired AI-900 on 30 June 2026 and replaced it with AI-901: Microsoft Azure AI Fundamentals. The new exam is still "fundamentals", but it is far more hands-on: 55–60% of it is about implementing solutions in Microsoft Foundry (prompts, agents, small Python clients, speech, vision, image generation and information extraction) and 40–45% is concepts (responsible AI, how models work, which model to pick, what the AI workloads are). Classic machine learning (AutoML, regression vs. clustering) is no longer on the exam. This course follows the official skills outline item by item.

AI-901 is not a vocabulary test. It asks whether you can build in Foundry and explain what you built.Today you do both, eight times, on one fictional car company's real problems.

What AI-901 measures, and where you will meet it today

Identify AI concepts and capabilitiesResponsible AI principles · how generative models work · choosing a model, deployment type and parameters · recognising workloads: generative & agentic AI, text, speech, vision, information extraction
40–45%
Implement AI solutions by using Microsoft FoundryPrompts · deploy a model and use the playground · a chat client with the Foundry SDK · build and test an agent, then call it from code · text analysis · spoken prompts with a multimodal model · Azure Speech · vision with a multimodal model · image generation · Content Understanding for documents, images, audio and video
55–60%

Passing score is 700 of 1000. The exam expects you to recognise Python, REST calls and CLI commands when you see them, not to write them from memory. That is why every lab here has a Portal path, a Cloud Shell path and a short Python path. Do the portal path first, then at least look at the code.

How the shared garage works

Twenty crews, one garage, zero collisions: your number is your namespace, S0 never F0, and deployments small enough that twenty of them fit the regional quota.

Twenty people build in one Azure subscription at the same time. Three rules keep you from stepping on each other:

1 · Your number is your namespaceEvery resource you create carries your student number: rg-ai901-s07, ai901-s07-pitcrew, proj-ai901-s07. Type your number into the Pit board box in the top bar and every snippet on this site updates.
2 · One Foundry resource each, in East US 2You create a single Azure AI Foundry resource (kind AIServices, tier S0). It serves OpenAI models, Language, Speech, Vision and Content Understanding from one endpoint and one key. Free F0 tiers are not used: only one F0 per service type is allowed per subscription, so the second student would fail.
3 · Small deploymentsModel quota is shared per region. Deploy gpt-4.1-mini at 10K tokens per minute, gpt-audio-mini at 1K and FLUX.2-pro at capacity 1. Twenty of each fits under the subscription limits with room to spare.
💡
Why these names

The Foundry resource name becomes a public DNS name (https://ai901-s07-pitcrew.cognitiveservices.azure.com), so it must be unique in the world, not just in our subscription. If creation fails with "already taken", change the last word (pitcrew → garage, turbo, your surname) and keep going.

What you need

  • A browser and your Azure sign-in for the shared subscription. The instructor will give you a student number (s01–s20) on the whiteboard.
  • Nothing installed. Every command runs in Azure Cloud Shell, which already has the Azure CLI, Python and pip. If you prefer your laptop, you need az and Python 3.10+.
  • About 20 lines of Python reading ability. You will not write code from scratch; you will run and edit the pit-crew scripts provided.
  • Headphones for Lap 4 (we make the cars talk).

House rules

  • Keys are secrets. They go in environment variables, never in chat, screenshots or Git. Lap 0 shows you how.
  • Watch the meter. Everything today is pay-per-use. A full day costs about $2–4 per student if you follow the labs; a runaway loop generating images could cost more. Race control shows the live cost report.
  • Delete your resource group at the end. Lap 7 ends with one command that removes everything you built. Resources left running cost money while you sleep.
  • The portal moves. Microsoft renames and redraws Foundry often (it was "Azure AI Foundry" until November 2025). Where a button has moved, the Cloud Shell path on the same page is exact and always works.
  • Finish early? Overtake. Every lap ends with an Overtake box: two or three unguided challenges for anyone ahead of the field. They are optional and they are where the learning sticks.
  • Keyboard. Press ] for the next lap and [ for the previous one. Click any screenshot to zoom; Esc closes it.
