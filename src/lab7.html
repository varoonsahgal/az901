How the real exam works

  • AI-901: Microsoft Azure AI Fundamentals leads to the Microsoft Certified: Azure AI Fundamentals certification. It replaced AI-900, which retired on 30 June 2026. Skills measured are dated 15 April 2026; this course follows them.
  • Two domains: Identify AI concepts and capabilities (40–45%) and Implement AI solutions by using Microsoft Foundry (55–60%). Passing score is 700 of 1000; scoring is scaled, not a percentage.
  • Fundamentals exams typically run about 45 minutes with roughly 40–60 items: multiple choice, multiple response, drag-and-drop matching, hot-area and short scenario sets. You are expected to recognise Python, REST and CLI, not write them from memory.
  • Official preparation: the exam page, the study guide, the free practice assessment on AI Skills Navigator (sign in required) and the Microsoft Learning exercises we mirrored today.

Cool-down lap · delete everything

Everything you built today lives in one resource group. Deleting it removes the Foundry resource, its project, and every deployment, agent, vector store and analyzer inside them. You lose nothing you need: the scripts and documents are on this site. Then you purge the soft-deleted Foundry resource so its name and quota are freed.

This is why Lap 0 started with a resource group.You made the folder before anything went in it, so now one delete empties the whole garage. Nobody has to remember a list of seven laps of work.

  1. Look before you delete. Open portal.azure.com, search the top bar for Resource groups, and open rg-ai901-s07. The Overview lists two resources: your Foundry resource ai901-s07-pitcrew (type Foundry) and your project proj-ai901-s07 (type Foundry project).

    Why look firstDeleting a resource group cannot be undone. Check the title shows your number and the list holds only today's two resources.

    The list is short because everything else you made today lives inside those two.

  2. Delete the group. Select Delete resource group on the toolbar. The Delete a resource group pane lists every dependent resource that will go with it. Then:

    • 1Type the resource group name, rg-ai901-s07, in Enter resource group name to confirm deletion.
    • 2Select Delete.

    Why type the nameThe portal makes you prove you mean this group. In a shared subscription the group next to yours belongs to a colleague.

    Deletion takes a few minutes; a notification tells you when it is done.

  3. Purge the soft-deleted resource. A deleted Foundry resource is not gone yet: it is soft-deleted and kept for 48 hours so it can be recovered. During that time it still reserves the name ai901-s07-pitcrew and still counts against the subscription's quota. Purge it to free both: once the deletion notification arrives, open Cloud Shell and run the Cloud Shell tab's first line (your variables), then its last block. (If the portal's Foundry resources list shows Manage deleted resources, you can purge there instead.)

    Deleted is not the same as gone.Soft delete protects you from a slip of the finger, but the name and the quota stay taken until you purge. Race control purges anything left at the end of the day.

    Why this orderPurge only works on something already soft-deleted, so it has to wait for step 2 to finish. And purge is the one step with no way back: once it runs, the resource cannot be recovered. Look, delete, then purge.

Same result, by command: look, delete, check, purge. You only need two of your Lap 0 variables: everything else you built is found through the resource group.

export STUDENT=s07; export RG=rg-ai901-$STUDENT
az resource list --resource-group $RG --query "[].{name:name,type:type}" -o table     # look before you delete
az group delete --name $RG --yes --no-wait
az group list --query "[?starts_with(name,'rg-ai901')].{name:name,state:properties.provisioningState}" -o table

The deleted Foundry resource is soft-deleted for 48 hours: it still reserves its name and counts against quota. Purge it once the group has finished deleting (the group list no longer shows yours):

az cognitiveservices account list-deleted -o table
az cognitiveservices account purge --name ai901-$STUDENT-pitcrew --resource-group $RG --location eastus2

Why this matters

Pay-per-use services cost nothing when idle, but a forgotten Provisioned deployment, a running compute instance or an agent in a loop can cost real money overnight.

One resource group per experiment. Delete it when the experiment ends.It is the cheapest habit in cloud computing, and the one most people never form.
